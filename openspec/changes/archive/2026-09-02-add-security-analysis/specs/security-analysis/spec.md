# security-analysis Delta

## ADDED Requirements

### Requirement: Структурированные Находки

В агентном режиме security-ревью система SHALL позволять агенту фиксировать Находки инструментом; Находка MUST нести severity (critical/high/medium/low/info) и краткое название, MAY нести класс уязвимости (CWE), CVE, расположение (файл/строки), impact, evidence, уверенность и шаги устранения. Отчёт агентного Рана MUST включать перечень зафиксированных Находок.

#### Scenario: Агент фиксирует уязвимость

- **WHEN** агент в ходе ревью находит SQL-инъекцию и вызывает инструмент фиксации с severity=high и расположением
- **THEN** Находка попадает в Отчёт Рана с указанными полями

#### Scenario: Ран без Находок

- **WHEN** агент завершает ревью, не зафиксировав ни одной Находки
- **THEN** Отчёт содержит пустой перечень Находок и резюме, а не ошибку

### Requirement: Skills-справочник

Система SHALL предоставлять агенту загружаемые skills — именованные пакеты справки по классам уязвимостей и технологиям — и инструмент для их загрузки в текущий ход. Запрос неизвестного skill MUST возвращать внятную ошибку, а не молчание; число одновременно загружаемых skills MAY ограничиваться.

#### Scenario: Загрузка релевантного skill

- **WHEN** агент перед проверкой JWT запрашивает загрузку skill по аутентификации
- **THEN** содержимое skill возвращается как справка в ход агента

#### Scenario: Неизвестный skill

- **WHEN** агент запрашивает несуществующий skill
- **THEN** инструмент возвращает ошибку с перечнем допустимых имён

### Requirement: CVE-интеллект через MCP

Система SHALL уметь подключать внешние MCP-серверы (в частности CVE-интеллект) как источник инструментов для агента; их схемы предоставляются агенту отложенно (deferred-каталог), а не биндятся все сразу. Недоступный MCP-сервер MUST деградировать в предупреждение — Ран продолжается без его инструментов, а не падает.

#### Scenario: CVE-запрос агента

- **WHEN** MCP-сервер CVE подключён и агент запрашивает данные по конкретному CVE
- **THEN** агент получает инструмент из каталога и корреллированные данные по уязвимости

#### Scenario: MCP-сервер недоступен

- **WHEN** сконфигурированный MCP-сервер не поднимается
- **THEN** система логирует предупреждение и исполняет Ран без его инструментов
