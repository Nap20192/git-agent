# Proposal: backfill-system-specs

## Why

После первого change (`add-repo-scan-agent`) система выросла на несколько крупных подсистем — durable-рантайм Ранов, агентный режим с Лидом и Сабагентами, пресеты памяти, eval-харнес — но всё это строилось мимо OpenSpec: `openspec/specs/` описывает только пайплайн scan→parse→report. Спеки перестали быть источником правды о поведении системы. Этот change — backfill: фиксирует УЖЕ реализованное поведение как требования, чтобы дальнейшие изменения предлагались дельтами к честной базе.

## What Changes

- Новые спеки для четырёх существующих подсистем (кода этот change не меняет — требования списаны с реализации и её тестов/формальной модели):
  - durable-исполнение Ранов: идемпотентный submit, Возобновление, lease/fence, отмена, стрим событий;
  - агентный режим: Лид с делегированием Сабагентам (звезда глубины 1, Квитанции, лимиты);
  - Пресеты памяти: именованные конфигурации контекста, детерминированный резолв;
  - eval-харнес: замороженные Батареи, разделение платного прогона и офлайн-грейда, Гейт валидности, Фингерпринт.

## Capabilities

### New Capabilities

- `durable-runs`: Ран как долгоживущий ресурс — admission, идемпотентность, Возобновление, отмена, наблюдаемый стрим.
- `lead-delegation`: агентный режим — Лид, Сабагенты, Квитанции, лимиты делегирования.
- `memory-presets`: управление контекстом LLM внутри Рана через именованные пресеты.
- `eval-harness`: оценка системы Батареями — прогон, грейд, валидность, сравнение Армов.

### Modified Capabilities

- `agent-graph`: граф — больше не единственный режим и исполняется рантаймом, а не напрямую из CLI; уточнение требования запуска.

## Impact

- Только `openspec/specs/` (после архивации). Код, API и зависимости не меняются.
- Термины — по глоссарию `CONTEXT.md` (Ран, Лид, Сабагент, Батарея, Арм, Гейт валидности, Фингерпринт).
- Исполняемые зеркала требований остаются в силе: `formal/RuntimeCore.lean` + `tests/unit/test_runtime.py` (durable-runs), `tests/unit/subagents/` (lead-delegation), `tests/unit/eval/` (eval-harness). Спеки им не противоречат, а дают поведенческий уровень.
