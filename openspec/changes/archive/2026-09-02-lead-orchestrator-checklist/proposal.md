# Proposal: lead-orchestrator-checklist

## Why

Сейчас Лид сам читает файлы и ищет уязвимости, а делегирует редко — Сабагенты почти не используются, параллелизма нет, контекст Лида забивается. Нужен режим оркестратора (референс strix root-agent): Лид НЕ исследует сам, а активно делегирует Сабагентам проверку по чеклисту областей, собирает Находки и пишет резюме.

## What Changes

- **Промпт Лида — оркестратор**: Лид делегирует всю ручную работу Сабагентам через `task`; сам только строит карту (беглый обзор дерева), декомпозирует цель по чеклисту и агрегирует. Ручной разбор кода Лидом — вне роли.
- **Чеклист областей**: recon/карта → инъекции → XSS/шаблоны → аутентификация/доступ → SSRF/traversal/upload → десериализация/mass-assignment → секреты/крипто/раскрытие → бизнес-логика/гонки. По каждой релевантной области — делегация Сабагенту со скоупом файлов и skills.
- **Дефолтная задача** Рана переформулирована под оркестрацию.

## Capabilities

### Modified Capabilities

- `lead-delegation`: в security-режиме Лид действует как оркестратор — активно делегирует по чеклисту, сам не проводит ручной разбор.

## Impact

- `core/lead/graph.py` (LEAD_SYSTEM_PROMPT, _LEAD_TASK). Поведение агента меняется; тулы/контракт — нет.
