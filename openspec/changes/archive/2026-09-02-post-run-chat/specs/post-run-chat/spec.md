## Purpose

Дать пользователю продолжить разговор с лид-агентом после завершения агентного
Рана: задать уточняющий вопрос или попросить доисследовать — с полным контекстом
Рана и его инструментами, не запуская Ран заново.

## ADDED Requirements

### Requirement: Диалог поверх завершённого агентного Рана

Система SHALL позволять после агентного Рана отправить агенту сообщение и получить
ответ того же лид-агента, продолжающего его чекпоинт-тред (полная история хода
доступна агенту). Чат доступен только для Рана в agent-режиме.

#### Scenario: Вопрос после Рана

- **WHEN** пользователь шлёт сообщение агентному Рану, у которого есть чекпоинт
- **THEN** лид-агент отвечает, продолжая тот же тред, и его ответ стримится клиенту

#### Scenario: Чат недоступен для pipeline

- **WHEN** пользователь пробует чат с Раном в pipeline-режиме
- **THEN** система отклоняет запрос (у pipeline нет диалоговой истории)

### Requirement: Чат не мутирует Ран как ресурс

Чат-ход MUST NOT проходить durable-admission (claim/lease) и MUST NOT
перезаписывать терминальный статус или Отчёт Рана. Чат-ходы сохраняются отдельным
типом события и не входят в историю/граф/Отчёт исходного Рана.

#### Scenario: Терминальный статус неизменен

- **WHEN** пользователь ведёт чат с успешно завершённым Раном
- **THEN** статус Рана остаётся `succeeded`, а его Отчёт не меняется

### Requirement: Переиспользование окружения агента в чате

Чат-ход SHALL переподключаться к живому Экземпляру Сэндбокса Рана; при мёртвом —
поднимать свежий с подготовкой. Агенту в чате доступны его инструменты.

#### Scenario: Живой сэндбокс переиспользуется

- **WHEN** чат-ход стартует, а Экземпляр Сэндбокса Рана ещё жив
- **THEN** агент переподключается к нему без нового клона репозитория
