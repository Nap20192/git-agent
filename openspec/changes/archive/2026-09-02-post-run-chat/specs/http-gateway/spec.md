## ADDED Requirements

### Requirement: HTTP-чат с агентным Раном

Gateway SHALL отдавать историю чата Рана и принимать сообщение со стримингом ответа
(SSE-подобные кадры). Чат разрешён только для Рана в agent-режиме; для остальных —
отказ.

#### Scenario: Отправка сообщения стримит ответ

- **WHEN** клиент POST-ит сообщение агентному Рану
- **THEN** gateway стримит ходы ответа и по завершении сохраняет пользовательский и агентский ход

#### Scenario: История чата

- **WHEN** клиент запрашивает историю чата Рана
- **THEN** gateway возвращает сохранённые ходы (роль + текст) по порядку
