## ADDED Requirements

### Requirement: Управление Экземплярами Сэндбокса через HTTP

Gateway SHALL отдавать список Экземпляров Сэндбокса (живых и мёртвых) с их
статусами и позволять убить Экземпляр по id. Убийство идемпотентно: убийство уже
мёртвого Экземпляра возвращает успех.

#### Scenario: Список Экземпляров

- **WHEN** клиент запрашивает список Экземпляров Сэндбокса
- **THEN** gateway возвращает Экземпляры с их внешним id, статусом `alive`/`dead` и Раном-создателем

#### Scenario: Убийство по id

- **WHEN** клиент вызывает убийство `alive`-Экземпляра по id
- **THEN** gateway уничтожает удалённый сэндбокс и возвращает Экземпляр со статусом `dead`
