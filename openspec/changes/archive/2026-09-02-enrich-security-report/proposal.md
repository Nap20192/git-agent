# Proposal: enrich-security-report

## Why

Отчёт security-ревью беден: Находки только от Лида (Сабагент их фиксирует, но в структурированный отчёт они не попадают — только через текст, который Лид может не перенести), нет сводки (распределение по severity, кто нашёл), а рендер во фронте — плоский список. Нужны: (1) Находки Сабагентов в отчёте с атрибуцией, (2) сводка/метаданные, (3) красивый структурированный рендер.

## What Changes

- **Находки Сабагентов**: Сабагент фиксирует Находки инструментом `report_finding`; исполнитель собирает их из хода Сабагента и прикрепляет к терминальному результату; отчёт объединяет Находки Лида и Сабагентов с атрибуцией (кто нашёл), дедупом и сортировкой по severity.
- **Сводка отчёта**: распределение по severity, всего Находок, число делегаций, вызовов инструментов, затронутых файлов.
- **Рендер**: структурированный экран отчёта — полоса распределения severity, карточки Находок (цвет по severity, CWE/CVE, расположение, evidence-код, impact, remediation, confidence, атрибуция агента).
