## MODIFIED Requirements

### Requirement: Разделение платного прогона и офлайн-оценки

Платный прогон SHALL быть единственной фазой, обращающейся к приложению и внешним сервисам; он пишет вечные Бандлы. Грейд, Гейт валидности и отчёт SHALL работать офлайн только по Бандлам и MUST быть повторяемы неограниченно без доступа к приложению. Платные прогоны MUST запускаться только по явной команде пользователя. Реализация платной фазы поверх durable-gateway удалена; новая платная фаза SHALL исполнять Юниты через раннер (Экземпляр Агента по синтетическому Событию), сохраняя формат Бандлов.

#### Scenario: Повторный грейд спустя время

- **WHEN** грейд запускается повторно по тем же Бандлам
- **THEN** результат байт-в-байт совпадает с прежним, приложение не затрагивается

#### Scenario: Платная фаза отсутствует

- **WHEN** платная фаза ещё не перенесена на раннер
- **THEN** офлайн-грейд, Батарея и их тесты остаются рабочими по существующим Бандлам
