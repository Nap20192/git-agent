# agent-graph Delta

## ADDED Requirements

### Requirement: Пользовательская задача Рана

Система SHALL принимать при запуске Рана опциональную пользовательскую задачу (instructions) — из CLI и из HTTP API. В агентном режиме задача замещает дефолтную формулировку для Лида (упоминание `{repo_url}` подставляется значением); в pipeline-режиме задача игнорируется — его вход фиксирован. Возобновление продолжает Ран с Чекпоинта и MUST NOT переигрывать вход: задача действует при создании Рана.

#### Scenario: Кастомная задача в агентном режиме

- **WHEN** пользователь запускает агентный Ран с задачей «опиши каждую функцию»
- **THEN** Лид получает эту задачу вместо дефолтной и строит Отчёт по ней

#### Scenario: Задача не входит в идентичность

- **WHEN** пользователь повторно запускает ту же идентичность (Репозиторий, коммит, модель) с другой задачей
- **THEN** система присоединяется к существующему Рану (идемпотентность durable-runs), новая задача не применяется — это документированное ограничение
