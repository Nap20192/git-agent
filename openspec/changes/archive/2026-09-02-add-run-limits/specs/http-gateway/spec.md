# http-gateway Delta

## ADDED Requirements

### Requirement: Лимиты Рана

Submit SHALL принимать лимиты Рана — токен-бюджет, максимум одновременных Сабагентов, включение делегирования и loop-detection — и применять их к агенту. Лимиты MUST храниться на Ране и действовать на всех попытках, включая Возобновление.

#### Scenario: Запуск с токен-бюджетом

- **WHEN** пользователь запускает агентный Ран с токен-бюджетом
- **THEN** агент останавливается при исчерпании бюджета (stop_reason token_capped), а не работает без предела

### Requirement: Продолжение Рана с новыми лимитами

Возобновление Рана SHALL опционально принимать новые лимиты; переданные лимиты MUST заменять прежние перед продолжением, позволяя поднять бюджет и продолжить Ран, упёршийся в лимит.

#### Scenario: Поднять бюджет и продолжить

- **WHEN** Ран остановился по исчерпанию токен-бюджета, и пользователь возобновляет его с большим бюджетом
- **THEN** Ран продолжается с Чекпоинта под новым лимитом
