# memory-presets — Delta Spec

## ADDED Requirements

### Requirement: Продакшен-дефолт суммаризации

Продакшен-Пресет по умолчанию SHALL быть `prod_v3`: суммаризация истории треда Экземпляра запускается при 500 000 токенов контекста (стратегия structured_prefix, после компакции сохраняется ~50 000 токенов недавней истории, context editing выключен). Исторические Пресеты (`prod`, `prod_v2`) MUST оставаться неизменными — на них ссылаются сохранённые прогоны и evals.

#### Scenario: Ход без явного Пресета

- **WHEN** Ран запущен без явного Пресета и без переменной окружения
- **THEN** применяется `prod_v3`, и суммаризация срабатывает при достижении 500 000 токенов
