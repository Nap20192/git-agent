# Proposal: add-repo-scan-agent

## Why

Проект git-agent сейчас — каркас (заглушка `main.py`) с готовой инфраструктурой (конфиг, логгер, OpenSandbox, трейсинг). Нужна сама агентская система: LangGraph-граф, который принимает git-репозиторий, сканирует его структуру и разбирает код, возвращая структурированный отчёт.

## What Changes

- Новый LangGraph-граф агента в `main.py` (точка входа) с состоянием и узлами:
  - узел **scan** — клонирование/чтение репозитория и сканирование структуры (дерево файлов, языки, размеры, точки входа);
  - узел **parse** — разбор кода: модули, классы/функции, зависимости, при участии LLM;
  - узел **report** — сборка структурированного итогового отчёта.
- Небезопасные операции (клонирование чужого репо, выполнение кода/инструментов над ним) выполняются внутри песочницы OpenSandbox через существующий `infra/opensandbox.py`.
- Все узлы логируют через `pkg/logger.py`; вызовы LLM трейсятся в LangSmith (env) и Langfuse (callback handler).
- Конфигурация — только через существующий `core/config.py` (новые ключи добавляются туда и в `.env.example`).

## Capabilities

### New Capabilities
- `repo-scan`: сканирование структуры git-репозитория в песочнице — клонирование, дерево файлов, метаданные.
- `repo-parse`: разбор кода репозитория — извлечение модулей, символов, зависимостей и краткого описания.
- `agent-graph`: оркестрация scan → parse → report как LangGraph-граф с типизированным состоянием и наблюдаемостью (логи, трейсинг).

### Modified Capabilities

(нет — существующих спек ещё нет)

## Impact

- `main.py` — заглушка заменяется на CLI-точку входа агента.
- Новые модули графа (узлы, состояние) — новый пакет рядом с `core/`.
- Зависимости: уже установлены (langchain, langgraph, langfuse, opensandbox, structlog); потребуется провайдер LLM (langchain-anthropic или аналог).
- Требуется запущенный OpenSandbox (`deploy/docker-compose.yml`).
