# security-analysis — Delta Spec

## MODIFIED Requirements

### Requirement: CVE-интеллект через MCP

Система SHALL уметь подключать внешние MCP-серверы (в частности CVE-интеллект) как источник инструментов для агента; их схемы предоставляются агенту отложенно (deferred-каталог), а не биндятся все сразу. Раннер SHALL загружать инструменты сконфигурированных MCP-серверов при старте и передавать их Лиду каждого Экземпляра. Недоступный MCP-сервер MUST деградировать в предупреждение — Ран продолжается без его инструментов, а не падает.

#### Scenario: CVE-запрос агента

- **WHEN** MCP-сервер CVE подключён и агент запрашивает данные по конкретному CVE
- **THEN** агент получает инструмент из каталога и корреллированные данные по уязвимости

#### Scenario: MCP-сервер недоступен

- **WHEN** сконфигурированный MCP-сервер не поднимается
- **THEN** система логирует предупреждение и исполняет Ран без его инструментов

#### Scenario: MCP не сконфигурирован

- **WHEN** путь к MCP-серверу не задан
- **THEN** раннер стартует без MCP-инструментов и без `tool_search`
