# lead-delegation — Delta Spec

## MODIFIED Requirements

### Requirement: Security-инструменты агента

В режиме security-ревью Лид SHALL располагать инструментами фиксации Находок и загрузки skills, а Сабагенты — как минимум инструментом загрузки skills; обоим MAY предоставляться инструменты подключённых MCP-серверов. Находки консолидируются на уровне Лида: Сабагент возвращает найденное в своём отчёте, Лид фиксирует подтверждённые Находки. Системный промпт агента в этом режиме SHALL позиционировать его как авторизованное security-ревью кода репозитория.

И Лид, и Сабагенты SHALL располагать инструментами работы с кодом в Песочнице поверх порта Sandbox: чтение файла с постраничной выдачей и номерами строк, листинг дерева, поиск по коду с контекстом (ripgrep с fallback на grep), дифф коммита/диапазона и blame диапазона строк. Вывод каждого инструмента MUST усекаться до лимита контекста; ошибка команды MUST возвращаться моделью-читаемым текстом, а не исключением. Инструменты рассчитывают на образ Песочницы `git-agent/sandbox:latest` (git, ripgrep, jq, curl, python3+semgrep+bandit, node/npm, go+gosec, osv-scanner) и MUST NOT устанавливать анализаторы сами.

#### Scenario: Лид фиксирует находку

- **WHEN** Лид в security-режиме вызывает инструмент фиксации Находки
- **THEN** Находка попадает в Отчёт Рана

#### Scenario: Сабагент загружает skill

- **WHEN** Сабагент запрашивает skill по классу уязвимости
- **THEN** содержимое skill возвращается ему как справка

#### Scenario: Чтение большого файла по страницам

- **WHEN** агент читает файл с указанием смещения и числа строк
- **THEN** он получает только этот диапазон с номерами строк и общее число строк файла

#### Scenario: Поиск без совпадений

- **WHEN** агент ищет по коду паттерн, которого нет
- **THEN** инструмент возвращает текст «no matches», а не ошибку

#### Scenario: Дифф коммита События

- **WHEN** Экземпляр обрабатывает push-Событие с коммитом и агент запрашивает дифф этого коммита
- **THEN** инструмент возвращает изменения относительно родительского коммита без переклона Репозитория
