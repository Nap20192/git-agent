# repo-scan Specification

## Purpose
Сканирование структуры git-репозитория: получение дерева файлов и метаданных без выполнения кода репозитория на хост-машине.

## Requirements

### Requirement: Клонирование репозитория в песочнице

Система SHALL клонировать целевой git-репозиторий (по URL или локальному пути) внутри изолированной песочницы; недоверенный код репозитория MUST NOT выполняться на хост-машине.

#### Scenario: Клонирование публичного репозитория

- **WHEN** агент получает URL публичного git-репозитория
- **THEN** репозиторий клонируется внутри песочницы и его файлы доступны для сканирования

#### Scenario: Недоступный репозиторий

- **WHEN** URL недоступен или репозиторий не существует
- **THEN** агент завершает работу с внятной ошибкой в отчёте, без падения процесса

### Requirement: Сканирование структуры

Система SHALL строить структурный обзор репозитория: дерево файлов, распределение по языкам/расширениям, размеры, ключевые файлы (README, манифесты зависимостей, точки входа).

#### Scenario: Обзор структуры

- **WHEN** репозиторий склонирован
- **THEN** результат сканирования содержит дерево файлов, статистику по языкам и список ключевых файлов

#### Scenario: Игнорирование служебных директорий

- **WHEN** в репозитории есть `.git`, виртуальные окружения, кэши и сборочные артефакты
- **THEN** они исключаются из дерева и статистики
