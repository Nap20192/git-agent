# agent-graph Specification

## Purpose
Оркестрация этапов scan → parse → report как единого агентского графа с типизированным состоянием и полной наблюдаемостью каждого шага.

## Requirements

### Requirement: Последовательный граф с состоянием

Система SHALL исполнять этапы сканирования, разбора и сборки отчёта как граф с общим типизированным состоянием; результат каждого этапа MUST быть доступен последующим этапам через состояние.

#### Scenario: Полный прогон

- **WHEN** агент запускается с URL репозитория
- **THEN** этапы выполняются в порядке scan → parse → report и на выходе получается итоговый структурированный отчёт

#### Scenario: Ошибка этапа

- **WHEN** любой этап завершается ошибкой
- **THEN** граф завершается управляемо: ошибка фиксируется в состоянии и отчёте, песочница освобождается

### Requirement: Запуск из CLI

Система SHALL предоставлять запуск из командной строки с указанием целевого репозитория и выводить итоговый Отчёт. Запуск SHALL исполнять Ран через durable-рантайм (см. `durable-runs`), а не граф напрямую, и SHALL поддерживать выбор режима: линейный пайплайн scan → parse → report (дефолт) или агентный режим с Лидом (см. `lead-delegation`).

#### Scenario: Запуск с аргументом

- **WHEN** пользователь запускает CLI с URL репозитория
- **THEN** исполняется Ран (с идемпотентностью и Возобновлением durable-рантайма) и печатается итоговый Отчёт

#### Scenario: Выбор агентного режима

- **WHEN** пользователь запускает CLI с флагом агентного режима
- **THEN** Ран ведёт Лид, и Отчётом становится его финальный ответ

### Requirement: Наблюдаемость

Каждый этап SHALL писать структурные логи (начало, результат, ошибки), а вызовы LLM SHALL трейситься в LangSmith и Langfuse при наличии соответствующих ключей в конфигурации.

#### Scenario: Трейсинг включён

- **WHEN** в окружении заданы ключи LangSmith и/или Langfuse
- **THEN** вызовы LLM за прогон видны в соответствующем сервисе трейсинга

#### Scenario: Трейсинг не настроен

- **WHEN** ключи трейсинга отсутствуют
- **THEN** агент работает без ошибок, ограничиваясь локальными логами
