# repo-parse Specification

## Purpose
Разбор кода просканированного репозитория: извлечение модулей, символов и зависимостей и формирование краткого описания устройства проекта.

## Requirements

### Requirement: Извлечение структуры кода

Система SHALL извлекать из исходных файлов репозитория модули и их основные символы (классы, функции) и список внешних зависимостей проекта.

#### Scenario: Разбор Python-проекта

- **WHEN** просканированный репозиторий содержит Python-код и манифест зависимостей
- **THEN** результат разбора содержит перечень модулей с их классами/функциями и список внешних зависимостей

#### Scenario: Нечитаемые или бинарные файлы

- **WHEN** файл не является текстовым исходником или не парсится
- **THEN** файл пропускается с пометкой в логе, разбор остальных файлов продолжается

### Requirement: Смысловое описание

Система SHALL формировать с помощью LLM краткое описание назначения и устройства репозитория, опираясь на результаты сканирования и разбора.

#### Scenario: Описание проекта

- **WHEN** структура кода извлечена
- **THEN** итог разбора содержит связное текстовое описание: что делает проект и из каких основных частей состоит
