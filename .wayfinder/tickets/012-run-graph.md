## Question

Вернуть граф исполнения (звезда Лид→Сабагенты) в модель hub/Playground.

## Answer

- **Панель прямо в Playground** (+кнопка «развернуть» на весь экран).
- **Узел Сабагента**: статус (queued/working/done/failed/timeout — цвет/пульс), короткое описание задачи, длительность, счётчик Находок; клик → drawer с самоотчётом.
- **Охват — один ход**: по умолчанию последний (живой), любой прошлый выбирается кликом из ленты Событий ⇒ активность персистится per (Экземпляр, ход).
- **Live — SSE-стрим активности**: раннер отдаёт task_*/узловые события хода, hub проксирует (`GET /api/instances/{id}/activity`); тот же стрим кормит activity-лог (закрывает пункт 1 PLAYGROUND-TODO).
- **Дэшборд возвращаем**: сводка по Экземплярам (running/down, события за период, последние находки по severity) — вторым приоритетом после графа.
