# Стабильный адрес для вебхуков (Railway)

Type: wayfinder:grilling
Status: closed
Assignee: vnkjd
Blocked by: —

## Question

Заменить trycloudflare на постоянный публичный адрес для вебхуков.

## Answer

- **Релей-сервис на Railway** (вариант «очередь + длинный поллинг», не туннельный протокол): статичный Railway-домен принимает POST `/hooks/*` → складывает в очередь → **локальный пуллер** рядом с hub забирает длинным поллингом и переигрывает в `localhost:8081` с сохранением пути и заголовков — HMAC-подпись доезжает нетронутой, hub верифицирует как обычно.
- **Auth**: сами вебхуки защищает подпись провайдера; забор из очереди — токен `RELAY_TOKEN` (env у релея и пуллера).
- **Код — в отдельной верхнеуровневой папке `tunnel/`** (свой маленький Go-модуль: relay + puller).
- OAuth-callback остаётся на localhost (релей — только для вебхуков). `WEBHOOK_BASE_URL` = Railway-домен, `task tunnel`/rehook становятся почти ненужными (URL вечный).
- В туман: прод-путь — деплой самого hub на Railway (тогда посредник не нужен).
