# git-agent

Агентская система, которая по запросу пользователя разбирает git-репозиторий и превращает его в структурированное знание. Этот файл — глоссарий: единый язык проекта, без деталей реализации.

## Language

**Репозиторий (Repository)**:
Целевой git-проект, идентифицируемый нормализованным URL (host + owner/name; https- и ssh-формы — один Репозиторий). Форк — отдельный Репозиторий.
_Avoid_: проект, репа (в коде/схеме), source

**Ран (Run)**:
Одно логическое исполнение системы над Репозиторием на конкретном коммите с конкретной моделью. На пару (коммит, модель) существует один Ран: повторный запуск переиспользует его Отчёт, пересчёт — только по явному запросу пользователя.
_Avoid_: сессия, джоба, запуск (как термин модели)

**Возобновление (Resume)**:
Продолжение упавшего Рана с его последнего Чекпоинта. Это тот же Ран, а не новый: упавший Ран не финален, пока его явно не пересчитали или не завершили.
_Avoid_: перезапуск, retry

**Чекпоинт (Checkpoint)**:
Снимок состояния графа Рана после шага, позволяющий Возобновление. Принадлежит ровно одному Рану.

**Отчёт (Report)**:
Извлечённое знание о Репозитории — результат Рана. Первичное назначение — база для дальнейших вопросов к репозиторию; человекочитаемость вторична. (Точный состав уточняется.)
_Avoid_: результат, саммари

**Скан (Scan)**:
Этап Рана: получение Репозитория и обзор его структуры (дерево, языки, ключевые файлы) без чтения смысла кода.

**Разбор (Parse)**:
Этап Рана: извлечение устройства кода — модули, символы, зависимости — и его смысловое описание.
_Avoid_: анализ (слишком широкое)

**Песочница (Sandbox)**:
Изолированная среда, в которой выполняются все операции с недоверенным содержимым Репозитория. Живёт не дольше одного Рана.

**Пресет памяти (Memory preset)**:
Именованный набор правил управления контекстом LLM внутри Рана. Ран исполняется ровно с одним пресетом; имя пресета — часть идентичности эксперимента.
_Avoid_: конфиг памяти, настройки контекста

**Лид (Lead)**:
Агент, ведущий Ран в агентном режиме: сам решает, что читать в Песочнице и когда делегировать под-исследование Сабагенту. Его финальный ответ — Отчёт Рана.
_Avoid_: оркестратор, супервизор

**Сабагент (Subagent)**:
Агент с изолированным контекстом, исполняющий одно делегированное Лидом под-исследование. Делегирование — строго звезда глубины 1: Сабагент не делегирует дальше. Его результат — самоотчёт, который Лид не обязан принимать на веру.
_Avoid_: воркер, дочерний агент, таска

**Квитанция (Receipt)**:
Проверяемое свидетельство в самоотчёте Сабагента — цитата с привязкой к источнику, которую можно верифицировать вне доверия к самому Сабагенту.
_Avoid_: ссылка, пруф

**Батарея (Battery)**:
Замороженный набор Юнитов для оценки системы. Правка Батареи — это новая Батарея под новым именем, старая помечается устаревшей; истина в Батарее пишется человеком, никогда моделью.
_Avoid_: датасет, бенчмарк (как имя артефакта)

**Юнит (Unit)**:
Единица Батареи: Репозиторий, запиненный на коммит, плюс набор Фактов о нём и ожидаемый исход Рана.

**Факт (Fact)**:
Бинарно проверяемое утверждение о Репозитории внутри Юнита. Оценка Факта трёхзначна: подтверждён / опровергнут / неизмерим в данном режиме — неизмеримость не считается провалом.
_Avoid_: ассерт, критерий

**Арм (Arm)**:
Сравниваемая конфигурация эксперимента (режим × пресет × модель). Отчёт по оценке сравнивает Армы между собой.
_Avoid_: вариант, конфигурация (как термин сравнения)

**Бандл (Bundle)**:
Вечный сырой артефакт одного оценочного прогона Юнита в конкретном Арме. Грейд всегда пересчитывается из Бандлов офлайн; сами Бандлы не перезаписываются.

**Фингерпринт (Fingerprint)**:
Отпечаток научной конфигурации эксперимента — всего, что меняет поведение системы или её оценку. Результаты с разными Фингерпринтами несравнимы и не смешиваются.

**Гейт валидности (Validity gate)**:
Проверка «ось эксперимента реально применилась в этом Ране». Не прошедший гейт Бандл исключается из скоринга целиком, а не считается провалом.
_Avoid_: фильтр, дисквалификация
