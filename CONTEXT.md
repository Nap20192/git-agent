# git-agent

Агентская система, которая по запросу пользователя разбирает git-репозиторий и превращает его в структурированное знание. Этот файл — глоссарий: единый язык проекта, без деталей реализации.

## Language

**Репозиторий (Repository)**:
Целевой git-проект, идентифицируемый нормализованным URL (host + owner/name; https- и ssh-формы — один Репозиторий). Форк — отдельный Репозиторий.
_Avoid_: проект, репа (в коде/схеме), source

**Ран (Run)**:
Одно логическое исполнение системы над Репозиторием на конкретном коммите с конкретной моделью. На пару (коммит, модель) существует один Ран: повторный запуск переиспользует его Отчёт, пересчёт — только по явному запросу пользователя.
_Avoid_: сессия, джоба, запуск (как термин модели)

**Возобновление (Resume)**:
Продолжение упавшего Рана с его последнего Чекпоинта. Это тот же Ран, а не новый: упавший Ран не финален, пока его явно не пересчитали или не завершили.
_Avoid_: перезапуск, retry

**Чекпоинт (Checkpoint)**:
Снимок состояния графа Рана после шага, позволяющий Возобновление. Принадлежит ровно одному Рану.

**Отчёт (Report)**:
Извлечённое знание о Репозитории — результат Рана. Первичное назначение — база для дальнейших вопросов к репозиторию; человекочитаемость вторична. (Точный состав уточняется.)
_Avoid_: результат, саммари

**Скан (Scan)**:
Этап Рана: получение Репозитория и обзор его структуры (дерево, языки, ключевые файлы) без чтения смысла кода.

**Разбор (Parse)**:
Этап Рана: извлечение устройства кода — модули, символы, зависимости — и его смысловое описание.
_Avoid_: анализ (слишком широкое)

**Песочница (Sandbox)**:
Изолированная среда, в которой выполняются все операции с недоверенным содержимым Репозитория. Живёт не дольше одного Рана.

**Пресет памяти (Memory preset)**:
Именованный набор правил управления контекстом LLM внутри Рана. Ран исполняется ровно с одним пресетом; имя пресета — часть идентичности эксперимента.
_Avoid_: конфиг памяти, настройки контекста
