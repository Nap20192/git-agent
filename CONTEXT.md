# git-agent

Агентская система, которая реагирует на События в git-репозиториях: долгоживущий агент Репозитория исследует код в Песочнице, ведёт security-ревью и отвечает на вопросы пользователя. Этот файл — глоссарий: единый язык проекта, без деталей реализации.

## Language

**Репозиторий (Repository)**:
Целевой git-проект, идентифицируемый нормализованным URL (host + owner/name; https- и ssh-формы — один Репозиторий). Форк — отдельный Репозиторий.
_Avoid_: проект, репа (в коде/схеме), source

**Чекпоинт (Checkpoint)**:
Снимок состояния графа Экземпляра Агента после шага. Экземпляр поднимается с последнего Чекпоинта; тред Чекпоинтов принадлежит ровно одному Экземпляру.

**Отчёт (Report)**:
Итог хода Экземпляра по Событию: резюме и перечень Находок с атрибуцией нашедшего. Пишется агентом в БД через инструмент.
_Avoid_: результат, саммари

**Песочница (Sandbox)**:
Изолированная среда, в которой выполняются все операции с недоверенным содержимым Репозитория.

**Экземпляр Сэндбокса (Sandbox instance)**:
Реально провиженная Песочница с внешним id и статусом `alive`/`dead`. Создаёт и убивает её пользователь через hub (без TTL); Раннер только подключается к живому Экземпляру, привязанному к Экземпляру Агента.

**Событие (Event)**:
Тонкий факт о действии в Репозитории, пришедший с вебхука (provider, repo, action, commit/ref, пользователь) и опубликованный в очередь. Не несёт секретов и конфигурации; ничем не владеет — реакцию на него ведёт Экземпляр Агента.
_Avoid_: таск, джоба, сообщение (как термин модели)

**Сборка Агента (Agent build)**:
Хранимое в БД определение агента: LLM-подключение, sandbox-подключение, промпт и пресет памяти. Не живой процесс. Репозиторий привязан к одной Сборке.
_Avoid_: конфиг агента, профиль (зарезервировано на будущее)

**Экземпляр Агента (Agent instance)**:
Долгоживущий агент Репозитория: один на (Сборка, Репозиторий), с одним чекпоинт-тредом, копящим знание о репо. События и чат пользователя доливаются в его тред. Бывает `down` (чекпоинт в БД, в памяти нет) или `running` (в слоте Раннера, не больше одного running); опускается по idle-таймауту, поднимается с Чекпоинта.
_Avoid_: инстанс, запуск агента

**Раннер (Runner)**:
Процесс, слушающий очередь Событий и держащий слоты, в которых исполняются Экземпляры Агентов. Регистрируется и обозначает жизнь heartbeat'ом.
_Avoid_: воркер, нода

**Пресет памяти (Memory preset)**:
Именованный набор правил управления контекстом LLM внутри Экземпляра Агента. Экземпляр исполняется ровно с одним пресетом (из Сборки); имя пресета — часть идентичности эксперимента.
_Avoid_: конфиг памяти, настройки контекста

**Лид (Lead)**:
Агент Экземпляра: сам решает, что читать в Песочнице и когда делегировать под-исследование Сабагенту. Его ход по Событию завершается Отчётом.
_Avoid_: оркестратор, супервизор

**Сабагент (Subagent)**:
Агент с изолированным контекстом, исполняющий одно делегированное Лидом под-исследование. Делегирование — строго звезда глубины 1: Сабагент не делегирует дальше. Его результат — самоотчёт, который Лид не обязан принимать на веру.
_Avoid_: воркер, дочерний агент, таска

**Квитанция (Receipt)**:
Проверяемое свидетельство в самоотчёте Сабагента — цитата с привязкой к источнику, которую можно верифицировать вне доверия к самому Сабагенту.
_Avoid_: ссылка, пруф

**Батарея (Battery)**:
Замороженный набор Юнитов для оценки системы. Правка Батареи — это новая Батарея под новым именем, старая помечается устаревшей; истина в Батарее пишется человеком, никогда моделью.
_Avoid_: датасет, бенчмарк (как имя артефакта)

**Юнит (Unit)**:
Единица Батареи: Репозиторий, запиненный на коммит, плюс набор Фактов о нём и ожидаемый исход хода агента.

**Факт (Fact)**:
Бинарно проверяемое утверждение о Репозитории внутри Юнита. Оценка Факта трёхзначна: подтверждён / опровергнут / неизмерим в данном режиме — неизмеримость не считается провалом.
_Avoid_: ассерт, критерий

**Арм (Arm)**:
Сравниваемая конфигурация эксперимента (режим × пресет × модель). Отчёт по оценке сравнивает Армы между собой.
_Avoid_: вариант, конфигурация (как термин сравнения)

**Бандл (Bundle)**:
Вечный сырой артефакт одного оценочного прогона Юнита в конкретном Арме. Грейд всегда пересчитывается из Бандлов офлайн; сами Бандлы не перезаписываются.

**Фингерпринт (Fingerprint)**:
Отпечаток научной конфигурации эксперимента — всего, что меняет поведение системы или её оценку. Результаты с разными Фингерпринтами несравнимы и не смешиваются.

**Гейт валидности (Validity gate)**:
Проверка «ось эксперимента реально применилась в этом прогоне». Не прошедший гейт Бандл исключается из скоринга целиком, а не считается провалом.
_Avoid_: фильтр, дисквалификация
