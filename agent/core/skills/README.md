# Skills

Загружаемые пакеты справки по классам уязвимостей и технологиям. Каждый skill —
markdown с YAML-frontmatter (`name`, `description`) под `<category>/<name>.md`.
Агент подгружает их инструментом `load_skill` как справку в текущий ход
(постоянного изменения промпта нет). Загрузчик и тул — `core/skills/__init__.py`,
`core/tools/security/load_skill.py`.

Категории: `vulnerabilities` (классы уязвимостей), `frameworks` (методики под
конкретные фреймворки), `analysis` (калибровка severity, контрдоказательства,
source-aware поиск).

Содержимое скиллов адаптировано из проекта **strix** (референс security-агента);
взят код-релевантный поднабор для статического анализа исходников (live-recon,
cloud и protocol-скиллы не переносились). Новый skill — просто новый `.md` с
frontmatter в нужной категории; каталог резолвится по имени автоматически.
